# Ornate Padlock

Original model: **Ornate Padlock**, by [Annestra](https://sketchfab.com/Annestra).
[Source](https://sketchfab.com/3d-models/ornate-padlock-ce84edd8bf70444881c53682a0cd7de6).
Licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Adapted for this project: simplified geometry, grounded scale, and bronze/patina
vertex colors with a rough metallic material, and a separated/capped shackle for
the unlock animation. The original contains no textures.

Rebuild with `node scripts/prepare-padlock.mjs` using the supplied file at
`assets_referencia/padlock/ornate_padlock.glb`.
